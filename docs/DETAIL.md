# DeepSeek 网页版

在 DeepSeek Harness 的右侧栏中保留一个 DeepSeek 网页版标签页，随时切回同一段对话。

## 界面位置

左侧边栏底部、设置按钮上方出现「DeepSeek 网页版」入口；侧栏收窄为图标栏时显示为圆形按钮。点击展开面板，其中提供「打开」「新建标签」「页面异常」三个操作。点击后在右侧栏打开原生 Browser 标签页，地址指向网页版；已有标签页时直接聚焦，保持页面状态与当前对话。

快捷键为 `Ctrl/Cmd + Alt + D`。

## 操作说明

- 「打开」：打开或回到已有网页版标签页。
- 「新建标签」：另开一个 Browser 标签页并重新导航，适用于页面无响应时重来。
- 「页面异常」：展开加载失败、登录失效、嵌入受限与网络代理的检查项。
- Browser 标签页自带地址栏、后退、前进、重新载入与「在系统浏览器打开」。

## 首次运行提示

首次运行时面板自动展开，并给出一次内嵌环境说明：站点可能提示环境异常并建议使用官方客户端。插件只在本机打开该页面，不读取、不转发对话内容。点「不再提示」后不再出现。

## 会话与登录

对话内容、输入与回复均由网页版处理。首次使用需在标签页内登录；应用重启后内置 Browser 的进程内分区会清空，需要重新登录，账号下的历史对话仍可从网页版进入。

## 状态提示

右侧栏服务缺失、内置 Browser 未启用、地址不合规、无前台会话、标签页未创建等情况会在面板内直接显示原因，并提供重试。页面内部的加载错误由 Browser 自身的失败提示呈现。
