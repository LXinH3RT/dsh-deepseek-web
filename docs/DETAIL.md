# DeepSeek 网页版

在 DeepSeek Harness 的右侧栏中保留一个 DeepSeek 网页版标签页，随时切回同一段对话。

## 界面位置

左侧边栏底部、设置按钮上方出现「DeepSeek 网页版」入口；侧栏收窄为图标栏时显示为圆形按钮。**点一下就是打开**：点击入口即为打开动作，没有中间菜单，也不需要在面板里再选一次。点击后在右侧栏打开原生 Browser 标签页，地址指向网页版；当前会话已有标签页时展开右侧栏并聚焦它，保持页面状态与当前对话。

快捷键为 `Ctrl/Cmd + Alt + D`。

右上角面板只在有话要说时出现：首次运行的环境提示，或打开失败时的原因与检查项。

## 操作说明

- 点击侧栏底部入口：打开或回到已有网页版标签页。
- Browser 标签页自带地址栏、后退、前进、重新载入与「在系统浏览器打开」——页面无响应时用它重来。
- 打开失败时面板显示原因、重试按钮与检查项。

## 首次运行提示

首次点开入口时，面板展开并给出一次内嵌环境说明：站点可能提示环境异常并建议使用官方客户端。插件只在本机打开该页面，不读取、不转发对话内容。点「不再提示」后不再出现。

## 会话与登录

对话内容、输入与回复均由网页版处理。首次使用需在标签页内登录；应用重启后内置 Browser 的进程内分区会清空，需要重新登录，账号下的历史对话仍可从网页版进入。

为省去重复输入，可在插件配置中填写 `account` 与 `password`（并保持 `autoFill` 为开启）：插件会在页面加载后把账号密码键入登录表单，找到「登录 / Log in / Sign in」按钮时点击一次。页面没有密码输入框时不做任何改动。密码以明文保存在插件配置文件中，不填即关闭此功能。

## 状态提示

右侧栏服务缺失、内置 Browser 未启用、地址不合规、无前台会话等情况会在面板内直接显示原因，并提供重试。页面内部的加载错误由 Browser 自身的失败提示呈现。
